Reference for converting between decibels and linear gain.

Linear to Decibel

    
20.0f * log10(val);

Decibel to linear

    
powf(10.0f, val / 20.0f);

Useful values

Linear Decibel
0.5 -6dB Half gain
0.25 -12dB Quarter gain
0.000015 -96.0dB 16bit audio silence
1.25892541E-38 -758dB 32bit audio silence
